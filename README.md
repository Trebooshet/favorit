# Фаворит — поиск автозапчастей                                                                                                                  
                                                                                                                                                   
  Тестовое задание. Демо: https://favorit-mu.vercel.app                                                                                            
                                                                                                                                                   
  Запуск локально:                                                                                                                                 
                                                                                                                                                   
  ```                                                                                                                                              
  npm install                                                                                                                                      
  npm run dev                                                                                                                                      
  ```                                                                                                                                              
                                                                                                                                                   
  - Тестовый ключ API лежит в `.env`.                                                                                                              
  - API работает только по http, поэтому на Vercel (Демо) запросы идут через rewrite в `vercel.json`,
    локально — через proxy в `vite.config.js`.
